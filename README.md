# Dragon Pet Discord Bot 🐉

**Виртуальный дракон-питомец прямо в Discord!**

Корми, гладь, летай, собирай предметы, играй в мини-игры и расти своего доброго дракона с седлом.

Создан в духе [DragonForge-AI](https://github.com/dragongrok2-cloud/DragonForge-AI).

## ✨ Возможности

### Основные команды
| Команда | Описание |
|---------|----------|
| `/claim` | Завести своего дракона |
| `/status` | Статы + кнопки действий |
| `/feed` | Покормить |
| `/pet` | Почесать за ушком |
| `/fly` | Полететь |
| `/talk` | Поговорить |
| `/daily` | Ежедневная награда |

### Инвентарь и предметы
| Команда | Описание |
|---------|----------|
| `/inventory` | Посмотреть все предметы |
| `/use <item>` | Использовать / подарить предмет |

**Доступные предметы:**  
🍖 Сочное мясо • 🐟 Свежая рыба • 🍒 Огненная ягода  
💎 Блестящий камушек • 🧴 Масло для седла • 🛡️ Драконья чешуйка  
☁️ Сущность облака • 🪙 Древняя монета

### Мини-игры
| Команда / Кнопка | Описание | Кулдаун |
|------------------|----------|--------|
| `/search` / 🔍 | Поиск блестящих камушков и редких находок | 5 мин |
| `/hunt` / 🏹 | Охота за едой и ресурсами | 10 мин |

### Кнопки под сообщениями
🍖 Покормить • 🥰 Почесать • 🔥 Полететь  
🔍 Поиск камушков • 🏹 Охота • 🎒 Инвентарь

### Прогрессия
- **Уровни и XP** — каждое действие даёт опыт
- **Эволюция** — 5 стадий (от дракончика до Легендарного Небесного Дракона)
- **Привычки** — растут от взаимодействий
- **Эмодзи-реакции** — бот сам ставит реакции на действия

## 🚀 Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/Dragon-Pet-Discord-Bot.git
cd Dragon-Pet-Discord-Bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создай `.env`:
```
DISCORD_TOKEN=твой_токен_бота
```

Запуск:
```bash
python bot.py
```

## Токен и права

1. [Discord Developer Portal](https://discord.com/developers/applications)
2. Bot → Reset Token
3. Включи **Message Content Intent**
4. OAuth2 → scopes: `bot` + `applications.commands`  
   Права: Send Messages, Embed Links, Add Reactions, Use Slash Commands, Read Message History
