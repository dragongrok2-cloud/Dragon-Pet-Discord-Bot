# Dragon Pet Discord Bot 🐉

**Виртуальный дракон-питомец прямо в Discord!**

Корми, гладь, садись в седло и летай со своим добрым драконом.  
Он растёт, получает уровни, эволюционирует, имеет привычки и настоящую душу.

Создан в духе [DragonForge-AI](https://github.com/dragongrok2-cloud/DragonForge-AI).

## ✨ Возможности

### Команды
| Команда | Описание |
|---------|----------|
| `/claim` | Завести своего дракона |
| `/status` | Посмотреть статы + кнопки действий |
| `/feed` | Покормить |
| `/pet` | Почесать за ушком |
| `/fly` | Сесть в седло и полетать |
| `/talk` | Поговорить с драконом |
| `/daily` | Ежедневная награда (раз в сутки) |

### Красивые кнопки
Под каждым статусным сообщением появляются кнопки:
- 🍖 **Покормить**
- 🥰 **Почесать**
- 🔥 **Полететь**
- 📊 **Статус**

Кнопки работают только у владельца дракона.

### Система уровней и опыта
- Каждое действие даёт XP
- При повышении уровня — бонусы к статам
- Прогресс-бар опыта прямо в embed

### Эволюция (5 стадий)
1. 🐣 Маленький дракончик с седлом (ур. 1)
2. 🐉 Молодой огненный дракон с седлом (ур. 5)
3. 🔥🐉 Добрый огненный дракон с седлом (ур. 12)
4. ✨🐉 Древний страж с пылающим седлом (ур. 20)
5. 🌌🐉 Легендарный Небесный Дракон (ур. 35)

### Ежедневные награды (`/daily`)
- Восстановление голода, счастья и энергии
- Бонусный опыт (растёт с уровнем)
- Шанс усилить или получить новую привычку

### Эмодзи-реакции
Бот автоматически ставит реакции:
- 🍖 при кормлении
- 🥰 при почесывании
- 🔥 при полёте
- ⭐✨ при повышении уровня / эволюции
- 🎁 при ежедневной награде

### Привычки
Привычки укрепляются от действий и влияют на характер дракона.

## 🚀 Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/Dragon-Pet-Discord-Bot.git
cd Dragon-Pet-Discord-Bot
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Создай файл `.env`:
```
DISCORD_TOKEN=твой_токен_бота
```

Запуск:
```bash
python bot.py
```

## Токен и интенты

1. Создай приложение на [Discord Developer Portal](https://discord.com/developers/applications)
2. Bot → Reset Token → скопируй
3. Включи **Message Content Intent**
4. OAuth2 → URL Generator → scopes: `bot` + `applications.commands`  
   Нужные права: Send Messages, Embed Links, Add Reactions, Use Slash Commands, Read Message History
