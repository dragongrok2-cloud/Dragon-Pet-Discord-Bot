# Dragon Pet Discord Bot 🐉

**Полноценный виртуальный дракон-питомец в Discord**

Корми, летай, собирай, торгуй, дружи и проходи испытания вместе со своим добрым драконом с седлом.

## ✨ Возможности

### Основные
`/claim` `/status` `/feed` `/pet` `/fly` `/talk` `/daily`

### Инвентарь и экономика
| Команда | Описание |
|---------|----------|
| `/inventory` | Посмотреть предметы и монеты |
| `/use <item>` | Использовать предмет |
| `/shop` | Открыть магазин |
| `/buy <item> [кол-во]` | Купить |
| `/sell <item> [кол-во]` | Продать |
| `/gift @user <item>` | Подарить другому дракону |

**Валюта:** 🪙 Монеты (получаешь с daily, охоты, колец, уровней)

### Мини-игры
| Команда / Кнопка | Описание | Кулдаун |
|------------------|----------|--------|
| `/search` 🔍 | Поиск камушков и редкостей | 5 мин |
| `/hunt` 🏹 | Охота за едой и ресурсами | 10 мин |
| `/play` ⚽ | Весёлая игра (счастье) | 3 мин |
| `/rings` 🌀 | Полёт сквозь кольца (монеты + XP) | 7 мин |

### Система дружбы
| Команда | Описание |
|---------|----------|
| `/friend @user` | Добавить дракона в друзья |
| `/friends` | Список друзей и уровень дружбы |
| `/gift` | Подарки укрепляют дружбу |

### Кнопки
🍖 Покормить • 🥰 Почесать • 🔥 Полететь  
🔍 Поиск • 🏹 Охота • ⚽ Играть • 🌀 Кольца • 🎒 Инвентарь

### Прогрессия
- Уровни и XP
- 5 стадий эволюции
- Привычки
- Эмодзи-реакции

## 🚀 Запуск

```bash
git clone https://github.com/dragongrok2-cloud/Dragon-Pet-Discord-Bot.git
cd Dragon-Pet-Discord-Bot
pip install -r requirements.txt
```

Создай `.env`:
```
DISCORD_TOKEN=твой_токен
```

```bash
python bot.py
```

## Права бота
Send Messages, Embed Links, Add Reactions, Use Slash Commands, Read Message History  
+ **Message Content Intent**
